# Hinweise für KI-Assistenten (Cursor, Claude, ...)

Dieses openOMSI ist Martins erweiterte Fassung (Spline-Editor, Busunternehmen, Betriebshof).

1. Lies `CURSOR-UEBERGABE.md`: was gebaut ist, welche Dateien wozu, was offen ist.
2. Die Regeln stehen in `.cursor/rules/` (Arbeitsweise, Bauen, Code-Regeln).
3. Kurz: Deutsch und einfach mit Martin reden, Code vor dem Ändern lesen, kleine Schritte,
   nach jeder Änderung `cmd /c pruefen.cmd`, Tests mit `cmd /c testen.cmd ...`, dann
   `cmd /c bau-schritt.cmd fast`. Nichts als „funktioniert“ melden, was Martin nicht getestet hat.
